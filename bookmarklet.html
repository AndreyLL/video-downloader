🎬 Video Downloader Bookmarklet

Установка:

  1. Перетащите эту кнопку в закладки браузера:
🎬 Find Videos

Использование:

  1. Откройте страницу с видео (например, Monari)
  2. Нажмите на закладку "Find Videos"
  3. Появится окно со списком найденных видео
  4. Кликните на URL чтобы скопировать
  5. Используйте yt-dlp для скачивания

Скачивание через yt-dlp:

После копирования ссылки, используйте команду:

yt-dlp "ВСТАВЬТЕ_ССЫЛКУ_ЗДЕСЬ"

Установка yt-dlp:

pip install yt-dlp
